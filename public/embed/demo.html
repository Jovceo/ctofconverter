Embed demo

Everything below is produced by one <script> tag per table. No build step, no package, no tracking, no cookies — the widget fetches the same public JSON this site publishes and styles itself after the page it lands on, including dark mode.

These charts are here to prove the snippet works. The canonical documentation is /data-api.

<script src="https://ctofconverter.com/embed/ref-chart.js"
        data-set="oven-conversions"
        data-cols="gas_mark,conventional_c,fan_c,conventional_f,descriptor"></script>
<script src="https://ctofconverter.com/embed/ref-chart.js"
        data-set="safe-internal-temperatures"
        data-cols="product,min_fahrenheit,min_celsius,rest_minutes"></script>
<script src="https://ctofconverter.com/embed/ref-chart.js"
        data-set="human-body-temperature"
        data-cols="label,c_min,c_max,source"
        data-max="9"></script>

Data: ctofconverter.com · CC-BY-4.0 for the numbers, MIT for the widget code. Each row states the source it was checked against, and the file states the date.
