## 0. 一句话结论

**不是"没被抓"，是"抓了不收"。** Google 侧整站处于算法性质量降级（2026-04-26 起，4 个月未解除）：抽样 40 个 URL 中只有首页处于 "Submitted and indexed"，33 个 "Crawled – currently not indexed"，4 个 "URL is unknown to Google"。技术层没有任何故障（抓取成功、robots 允许、canonical 自指、4xx/5xx≈0），所以**提交 sitemap / IndexNow / 请求收录都不会改变结果**。Bing 侧在自愈（收录数 8-18 见底 172 → 8-25 回升 185），且昨天还在抓关键页。

## 3. 判读：三层原因，只有两层可动

| 层 | 实测证据 | 可动性 |
|---|---|---|
| 技术/抓取 | fetch SUCCESSFUL、robots ALLOWED、canonical 自指、4xx≈0、sitemap 无错误 | 无故障可修；提交类动作是空转 |
| 站点信任 | 4-26 断崖 + sitemap indexed=0 + 40 抽样仅首页收录 + 外链 AnchorCount=0 | 只能通过"缩小伤害面 + 提高单页价值 + 外部投票"缓慢换回 |
| 单页价值 | 即使被收录时 pos 27–90、CTR≈0.01%；温度换算 SERP 由大站垄断 | 只有 2–3 个独特数据页（烤箱/发烧图表）有 winning 可能 |

## 4. 决定（2026-08-27 站长授权 agent 代定）

**这个域名不再是收入载体。** 只保留一个代价极小、且防止未来误操作的止血变更，其余 SEO 动作全部停。

### 已做（本轮代码，待部署）
- **P0 语言矩阵收口**：非 `en` locale 全站 `noindex, follow`，页面仍 200、仍可内链跳转、不删不 301。实现：`utils/locale-config.ts` 新增 `getRobotsDirective()` / `isIndexableLocale()`，接线 `components/Layout.tsx`、`pages/index.tsx`、`pages/fahrenheit-to-celsius.tsx`。
- **hreflang 模板级收敛**（同时关掉原 ToDo 里的“hreflang 全站审计”）：只有英语页声明，且只声明自身 `en` + `x-default`；非英语页不再输出 `rel="alternate"`。`npm run build` 产物实测：`en/0-c-to-f` = `index, follow` + 2 条 alternate；`/es`、`/ja/0-c-to-f`、`/de/20-c-to-f`、`/es/fahrenheit-to-celsius` = `noindex, follow` + 0 条 alternate。
- 构建产物计数（可当规模基线）：共 **640** 个 prerendered HTML，其中 **576（90%）为语言副本**，英语页 64 个。

### 停做（原计划作废，不是“以后再说”）
- P1 sitemap 瘦身（62→15）、逐页重写 15 个超长 desc、第二批温度页精做、任何形式的外链建立/目录提交。
- 理由：这些动作均不改变“没需求”这个根因；被降级前单月 4 万展示也只换 0–8 次点击，收录 ≠ 收入。

### 保留的低成本动作
- GSC UI 对 10 个核心页 Request Indexing（只能站长做；每周 ≤10）。不做也不影响主线。
- 仪表盘：每周跑一次本目录脚本，只记 3 个数（`sitemap indexed`、抽样中 “Crawled – not indexed” 占比、Bing `InIndex`）；IndexNow 保持暂停；广告/联盟保持 `enabled=false`。
