## 一、已确认的决策

| 决策项 | 选择 | 理由 |
|--------|------|------|
| 旧 HTML 文件 | 不删除，保持现状 | 有对应 Next.js 页面的已 301（已验证），没有的等做新页面时自动 301 |
| noindex header | 不加 | 旧页面内容较薄，Google 本身不会优先索引，等新页面做好后自然替代 |

| sitemap | 全量英语页面放入，精做页面高 priority | 让 Google 发现所有页面，同时优先抓取高质量页面 |
| 内容策略 | 逐页手写，做一个提交一个 | 质量可控，风险最低 |

### 2.3 每个页面的编写流程（遵循 AGENTS.md）

```
1. 关键词调研
   └─ 在 Google SERP 确认 "{celsius} c to f" 有真实搜索量
   └─ 检查站内是否已有覆盖此内容的页面

2. 分析 SERP 前 5 名
   └─ 看竞品做到什么程度
   └─ 找到信息缺口

3. 规划信息增益点
   └─ 你比前 5 名多提供什么价值？
   └─ 例如：37°C 页面加婴儿 vs 成人发烧标准对比表

4. 写 Answer Capsule（40-60 字）
   └─ 直接答案，放在 H2/H3 下第一段
   └─ 例如："37 degrees Celsius equals 98.6 degrees Fahrenheit. This is the normal human body temperature."

5. 写正文
   └─ H2/H3 分段，每段以 Answer Capsule 开头
   └─ 包含该温度特有的上下文
   └─ 引用权威数据来源

6. 添加结构化数据
   └─ 表格/列表
   └─ FAQ Schema (JSON-LD)
   └─ HowTo Schema（如适用）

7. 写 FAQ（3-5 个真实问题）
   └─ 每个问答 40-60 字
   └─ 用 JSON-LD 标记

8. 添加内部链接
   └─ 链接到相关专题页（如 fever-chart、fan-oven-conversion-chart）
   └─ 链接到相邻温度转换页
```

## 四、textSpinner 处理策略

### 当前状态

`textSpinner.ts` 在 `TemperaturePage.tsx` 中被 8+ 处调用，用于生成文案变体（步骤说明、介绍段落、FAQ 等）。

### 处理方式

**不一次性移除**，而是随每个页面的精做逐步替代：

1. 精做页面使用 `RoomTemperaturePage` 组件，该组件已设置 `disableSmartFaqs={true}`，跳过 textSpinner 的 FAQ 生成
2. 页面 JSON 中手写的 `faq`、`header.title`、`conversion.intro` 等字段会覆盖 textSpinner 的输出
3. 当所有页面都迁移到 `RoomTemperaturePage` + 手写 JSON 后，再统一从 `TemperaturePage.tsx` 移除 textSpinner 调用
4. 最后删除 `utils/textSpinner.ts`

### textSpinner 调用与替代对照

| textSpinner 方法 | 当前用途 | 精做页面的替代 |
|---|---|---|
| `getStep1(celsius, t)` | 生成"第一步：乘以 1.8"文案变体 | 固定文案（公式步骤不需要变体） |
| `getStep2(celsius, step1, t)` | 生成"第二步：加 32"文案变体 | 固定文案 |
| `getConclusion(celsius, fahrenheit, t)` | 生成结论句变体 | 固定文案 |
| `getFormulaTitle(celsius, fahrenheit, t)` | 生成公式标题变体 | 固定文案 |
| `getConverterTitle(celsius, fahrenheit, t)` | 生成转换器标题变体 | 从页面 JSON `header.title` 读取 |
| `getIntroValue(celsius, fahrenheit, t)` | 生成介绍段落数值变体 | 从页面 JSON `conversion.intro` 读取 |
| `getIntroConnect(celsius, t)` | 生成上下文连接句变体 | 从页面 JSON `header.tagline` 读取 |
| `getIntroText(celsius, f, locale, fn, t)` | 生成带链接的介绍文变体 | 从页面 JSON `comfortGuide.intro` 读取 |
| `getSmartFAQ(celsius, fahrenheit, t)` | 程序化生成 FAQ | 从页面 JSON `faq` 数组读取（`disableSmartFaqs={true}`） |
