## 三、核心发现（按重要性排序）

### 发现 1：Google 12 个月只带来 7 次点击 —— 流量 100% 来自 Bing

- GA4 Organic 高峰（2025-12）1,939 会话，同期 GSC Google 点击仅 **2 次**
- 差额 ~1,900 会话全部来自 Bing + DuckDuckGo（Bing 系）+ Yahoo
- 国家分布印证：UK（Bing 市场份额约 20-25%）是第 1 市场，12 月 1,029 个 organic 会话

**含义**：此前所有"谷歌 SEO 优化"都没带来流量。Bing 才是这个站的基本盘，Bing 崩溃 = 收入归零。

### 发现 2：2026 年 1 月 Google + Bing 同时崩溃，与 Next.js 迁移时间重合

- Bing 展现：2025-12 的 311,395 → 2026-01 的 **7**（彻底消失）；点击 1,109 → 0
- Google 平均排名：2025-12 的 43.9 → 2026-01 的 74.6（掉到第 8 页之后）
- Git 历史：2026-01-05 ~ 01-23 有数百个迁移相关提交（pages/*.tsx 批量创建、vercel.json、next.config.js 变更）
- 2025-12-13 还有一次全站 title/meta 批量改写（"Revise title and meta descriptions for SEO"）

**判断**：两个引擎同时掉，说明是站点级技术/结构问题（迁移导致 URL 结构、模板、内容同时变化），不是 Google 算法单独降权。Bing 恢复快（6 月已重新收录 214+ 页），Google 恢复慢，与"Google 需要重新评估整站"的表现一致。

## 五、数据缺口（下次拉取建议补充）

1. GSC query 维度缺 country 字段 —— 无法区分 Google 各国家市场（需 API 加维度）
2. GA4 数据缺 page 维度（本次拉取未含 pagePath）—— 无法做页面级 GA 分析，只能用 GSC/Bing 补
3. Bing CrawlStats 只有汇总，缺具体 URL 抓取日志
4. 建议下次拉取加：GSC page+date（页面级时间趋势）、GA4 含 pagePath、Bing IndexNow 状态
